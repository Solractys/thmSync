# system-palette.nvim

A Neovim colorscheme that follows a Material 3 palette generated by Matugen.
If your Hyprland setup already exports the same palette as JSON, Neovim can
follow wallpaper changes without needing a running Hyprland session.

## Requirements

- Neovim 0.10 or later
- A flat Material 3 JSON palette, such as the one generated by illogical-impulse

## Install with lazy.nvim

Use a local checkout with the following spec. For a hosted checkout, replace
`dir` with the repository slug as the first entry in the spec.

```lua
{
  dir = vim.fn.expand("~/Projects/system-palette.nvim"),
  lazy = false,
  priority = 1000,
  opts = {},
}
```

Run `:colorscheme system-palette` to activate the theme. For LazyVim, you can
make it the startup theme with this spec:

```lua
{
  "LazyVim/LazyVim",
  opts = {
    colorscheme = function()
      local palette = require("system-palette")
      vim.cmd.colorscheme(palette.available() and "system-palette" or "habamax")
    end,
  },
}
```

## Configuration

By default, the plugin reads
`$XDG_STATE_HOME/quickshell/user/generated/colors.json` (or
`~/.local/state/quickshell/user/generated/colors.json` if unset). Override it
with `opts = { path = "~/path/to/colors.json" }` in lazy.nvim or pass the same
options to `require("system-palette").setup()` with another plugin manager.

The file must provide `surface`, `on_surface`, and `primary` as six-digit
hex colors. `background` and `on_background` are accepted as alternatives
for the first two roles. Optional Material 3 roles include `secondary`,
`tertiary`, `outline`, `surface_container`, `secondary_container`,
`on_secondary_container`, and `error`.

While the colorscheme is active, Neovim reloads it automatically when the
palette changes. If the file is temporarily invalid or missing, the last
applied colors stay visible. Set `watch = false` to disable automatic
reloads. Use `:SystemPaletteReload` to load the palette manually.
